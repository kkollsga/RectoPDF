# Sources for the 0.1.1 notes

Private working file: where each line of `docs/releases/0.1.1.md` comes from, so every claim can be checked. Not published with the release. Hashes are on `main`; a merge is named by its merge commit, a fix inside it by its own commit. "Plan" is `docs/PLAN.md` as of `a35e41b4`; quote the start of the line to find it. "0.1.0: by its code" means a commit or the plan says the fault is at `v0.1.0` (`dea9f10e`) by reading its code; "0.1.0: run" means it was reproduced on 0.1.0's code. Written 2026-11-15 from `git log v0.1.0..main` (134 first-parent merges, 125 direct commits, 1,660 commits in all) and the plan, not from memory.
